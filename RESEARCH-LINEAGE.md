# ANNE Research Lineage

## Status: Foundational Core Layer — Active Development

`anne-core` is the **first foundational/core engine layer of the current ANNE development direction**.

The lineage is intentionally separated into three roles:

```text
anne
  → first/main ANNE line
  → FROZEN / historical reference

anne-ai
  → current ANNE research platform
  → active architectural development

anne-core
  → first foundational/core engine layer
  → active development of reusable, installable core capabilities
```

### Why this repository exists

The original `anne` repository represents the first/main development line and is frozen as a historical research snapshot. The current architectural direction is developed on `anne-ai`.

`anne-core` is developed alongside `anne-ai` as the foundational core layer: capabilities that can be isolated, tested, reused, and installed independently can be developed here.

Platform-level architecture, integration work, experiments, and broader research milestones remain associated with `anne-ai`.

This repository is a research prototype and does not claim achieved AGI, a deployed global ANNE knowledge network, or unsupervised high-stakes autonomous operation.
